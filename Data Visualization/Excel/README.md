# Excel Dashboard README  
## Dual Insights: Income Analysis & Multi-Province Sales Performance

## Platform Overview: Why Excel?
Microsoft Excel remains a powerful platform for dashboarding due to its:
- **Familiar Interface**: Widely used across industries
- **Interactive Features**: Slicers, pivot tables, dynamic charts
- **Data Connectivity**: Supports imports from databases, CSVs, APIs
- **Custom Calculations**: Advanced formulas and conditional formatting
- **Portability**: Easily shared and versioned across teams

## Dashboard 1: Income Dashboard

### Purpose
To analyze income, expenses, and profit trends across demographic segments using Excel’s dynamic charting and tabular tools.

### Key Metrics
- **Income**: 1.17M  
- **Expenses**: 29.34M  
- **Profit**: -28.18M  
- **Revenue**: 1,202.59M  

### Visual Components
- **Pie Charts**:
  - Employment Rate (56.1%)
  - Income by Gender (43%)
  - Income Distribution (largest segment: 25.5%)
- **Bar Chart**: Income by Age Group
- **Line Chart**: Income Trends Over Time
- **Data Table**: Age Group, Income, Expenses, Profit, Revenue
- **Sidebar Navigation**: Overview, Income, Expenses, Profit, Revenue, Age Group, Gender, Employment, Distribution, Settings

### Use Cases
- Financial health assessment by demographic
- Gender and age-based income analysis
- Expense-to-income ratio tracking

## Dashboard 2: Multi-Province Store Sales Dashboard

### Purpose
To monitor sales performance across cities, branches, and product lines using Excel’s region-based mapping and product segmentation tools.

### Key Metrics
- **Sales**: 6,705,105.02  
- **Revenue**: 6,901,700.19  

### Visual Components
- **Circular Charts**: Sales and Revenue
- **Bar Chart**: Total Revenue Per Product
- **Line Chart**: Average Profit by Product
- **Pie Chart**: Sales Distribution (49.98%)
- **Data Table**: City-level breakdown of revenue, profit, and sales
- **Filters**: City, Store, Product, Date

### Use Cases
- Regional sales optimization
- Product line profitability analysis
- Branch-level performance tracking
