# Google Sheets Dashboard

## Overview
This dashboard provides a detailed analysis of Adidas product sales across U.S. regions, retailers, and product categories. Built in **Google Sheets**, it leverages spreadsheet-based interactivity and cloud accessibility to support sales tracking, margin analysis, and regional performance review.

**Access the dashboard here**: [Adidas Company Sales Dashboard – Google Sheets](https://docs.google.com/spreadsheets/d/1mBcJlzFhI2WlupKBGLKjSBDXENpld5NckOPIgugwd94/edit?usp=sharing)

---

## Platform Highlights: Why Google Sheets?
- **Cloud-Based Access**: View and collaborate from any device
- **Real-Time Updates**: Changes reflect instantly across users
- **Integrated Tools**: Supports pivot tables, slicers, charts, and Looker Studio exports
- **Version Control**: Track edits and restore previous versions
