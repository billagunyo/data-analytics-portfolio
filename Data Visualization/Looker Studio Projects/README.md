## Dual Insights: Sales Performance & Health Analytics

## Platform Overview: Why Looker Studio?
[Looker Studio](https://lookerstudio.google.com/) is Google’s cloud-based data visualization platform that enables users to build interactive, shareable dashboards from diverse data sources. These dashboards are:
- **Web-accessible**: No software installation required
- **Filterable & Dynamic**: Users can interact with slicers, date ranges, and dropdowns
- **Collaborative**: Shareable via secure links for team and executive review
- **Scalable**: Supports real-time updates and large datasets

---

## 🔗 Dashboard 1: [Amazon Sales Dashboard](https://lookerstudio.google.com/reporting/de2194c1-2a48-46d4-a5ca-ef73088f395c)

### Purpose
To monitor and analyze retail sales performance across products, regions, and retailers using Looker Studio’s dynamic filtering and visual storytelling.

### Key Features
- **Metrics**: Total Sales (899.9M), Units Sold (436.3K), Transactions (2.5M), Category Margin (0.42)
- **Visuals**:
  - Line chart for sales trends
  - Pie chart for sales methods
  - U.S. map for regional breakdown
  - Bar chart for profit per retailer
- **Filters**: Product dropdown, date range selector
- **Data Source**: Cloud-based retail transaction data

### Use Cases
- Regional sales optimization
- Retailer performance benchmarking
- Executive-level reporting

## 🔗 Dashboard 2: [Health Behavior & Condition Dashboard](https://lookerstudio.google.com/reporting/f55be96a-a941-4937-b07a-4d994fb27166)

### Purpose
To explore correlations between medical conditions, lifestyle factors, and demographic trends using Looker Studio’s multi-tabbed interface.

### Key Features
- **Metrics**: BMI (140.1), Heart Rate (82.4), Oxygen Saturation (94.25), Sleep Score (84.68), Stress Level (28.48)
- **Visuals**:
  - Pie chart for medical condition distribution
  - Bar chart for lifestyle vs. condition
  - Stress level by gender
  - Tab navigation: Medical Conditions, Common Conditions, Family History
- **Data Table**: Detailed health metrics across categories
- **Data Source**: Aggregated health records and wellness surveys

### Use Cases
- Public health research
- Wellness program design
- Gender-based stress analysis
